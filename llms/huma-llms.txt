# Huma

> Huma (Huma Therapeutics Limited) is a UK-headquartered digital health and remote
> patient monitoring company providing a regulated, configurable platform for
> building and running healthcare and life-sciences applications. It is CE-marked /
> EU MDR Class IIb medical-device software, ISO/IEC 27001 and ISO/IEC 13485
> certified. The developer surface exposes a backend Integration API plus native
> iOS, Android and Angular/web SDKs; API access is gated behind a Huma Workspace
> account.

## APIs
- [Huma Integration API](https://docs.huma.com/api-integration/intro): backend Integration API (JWT bearer / Hawk auth) for embedding Huma into first-party apps.
- [Huma Platform API (OpenAPI)](https://workspace-gcp-uk.api.huma.com/specs/): full OpenAPI 3.0.3, 984 operations, 76 tags (Auth, User, Deployment, Module Results, Appointment, Billing, Integration, Video Call, Medications, ...).
- [Huma Mobile & Web SDK](https://docs.huma.com/sdk/next/intro): iOS, Android, Angular SDKs (auth, Device Kit, charts, questionnaires, modules, messaging, call kit, storage).
